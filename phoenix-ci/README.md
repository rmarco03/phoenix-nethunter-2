# Phoenix Continuous Integration Framework

CI/CD automation framework for Phoenix NetHunter.

## Purpose

Automate:

- Code testing
- Build verification
- Hardware tests
- Documentation checks
- Report generation

## Pipeline

Commit

↓

GitHub Actions

↓

Phoenix CI

↓

Tests

↓

Build

↓

Report


## Target

Project:

Phoenix NetHunter

Architecture:

ARM64
