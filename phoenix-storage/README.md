# Phoenix Storage Framework

Storage management framework for Phoenix NetHunter.

## Purpose

Manage and document:

- Filesystem layers
- Storage devices
- Mount points
- Root filesystem preparation
- Image management
- Storage monitoring

## Target Device

Device:

iPhone9,1

Storage:

- Internal flash storage
- Linux filesystem layer

## Architecture


Phoenix Applications

↓

Phoenix Storage Framework

↓

Filesystem Layer

↓

Kernel Storage Interface

↓

Hardware Storage
