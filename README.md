# Phoenix NetHunter

Open source research project focused on developing a Kali Linux / NetHunter style environment for iPhone 7.

## Target Device

- Device: iPhone 7
- Identifier: iPhone9,1
- SoC: Apple A10 Fusion
- Architecture: ARM64
- Target iOS: 15.8.8

## Goal

Research and development of:

- Kali Linux ARM64 environment
- NetHunter framework
- Hardware documentation
- Linux compatibility research
- Driver research
