# Phoenix Hardware Abstraction Layer (HAL)

The Phoenix HAL provides a common interface between Phoenix NetHunter services and hardware components.

## Purpose

- Hardware identification
- Hardware information database
- Driver abstraction
- Future device support

## Target Hardware

Current target:

- iPhone9,1
- Apple A10 Fusion
- ARM64

## Components

- CPU
- GPU
- Display
- Touch
- USB
- WiFi
- Bluetooth
- Audio
- Sensors

Status: Research phase.
