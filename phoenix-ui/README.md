# Phoenix User Interface Framework

User interface framework for Phoenix NetHunter.

## Purpose

Provide interaction between users and Phoenix services.

## Features

- Command interface
- Graphical interface research
- System dashboard
- Notifications
- Themes
- Device status

## Architecture


User

↓

Phoenix UI

↓

Phoenix Service Manager

↓

Phoenix System Modules


## Target

Device:

iPhone9,1

Architecture:

ARM64
