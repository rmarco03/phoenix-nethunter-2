# Phoenix Kali Integration Framework

Integration framework between Phoenix NetHunter and Kali Linux ARM64.

## Purpose

Manage:

- Kali ARM64 root filesystem
- Kali package integration
- NetHunter tools
- Environment configuration
- User space management

## Architecture

Phoenix System

↓

Kali Integration Layer

↓

Kali ARM64 RootFS

↓

Linux Userspace


## Target

Device:

iPhone9,1

Architecture:

ARM64
